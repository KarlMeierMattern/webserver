Add: tsconfig.json
Configure: tsconfig.json
{
  "compilerOptions": {
    "target": "esnext",
    "module": "nodenext",
    "rootDir": "./src",
    "outDir": "./dist",
    "strict": true,
    "moduleResolution": "nodenext",
    "esModuleInterop": true,
    "skipLibCheck": true
  },
  "include": ["./src/**/*.ts"],
  "exclude": ["node_modules"]
}

rootDir is where your TypeScript files are located
outDir is where your compiled JavaScript files will go (you won't modify these - they're generated from your TypeScript files)
include specifies the files to include in the compilation
exclude specifies the files to exclude from the compilation
strict enables all strict type checking options
esModuleInterop allows you to use ES module syntax
moduleResolution specifies how modules are resolved
skipLibCheck skips type checking all declaration files

Configure package.json
add "type":"module". This means we can use the ES module syntax in our project for imports and exports.
add a build script that runs npx tsc - this will compile your TypeScript code to JavaScript.
add a start script that runs node dist/index.js - this will start the REPL.
add a dev script that runs a combination of the build and start scripts for convenience.

The npx command allows us to run the tsc command without installing TypeScript globally.

Enter the psql shell

Create a new database called chirpy
Run: CREATE DATABASE chirpy;

Connect to the new database
Run: \c chirpy
You should see a new prompt that looks like chirpy=#

Query the database
From here you can run SQL queries against the chirpy database.
For example, to see the version of Postgres you're running, you can run:

To exit the psql shell
Run: exit or \q

Install drizzle, postgres and drizzle-kit. Drizzle Kit is a CLI tool that will help us run our migrations and the Postgres driver allows drizzle and our program to talk to the database.
Run: npm i drizzle-orm postgres
Run: npm i -D drizzle-kit

Create src/db directory to hold database-related files
Create a schema.ts to define tables

Get your connection string. A connection string is just a URL with all the information needed to connect to a database. The format is:
protocol://username:password@host:port/database
macOS (no password, just your username): postgres://alexander:@localhost:5432/chirpy

Test your connection string
Run: psql postgres://alexander:@localhost:5432/chirpy
It should connect you to the chirpy database directly.
If it's working, great. Exit out of psql and save the connection string.

Create a drizzle.config.ts file at the root of your project. This file will contain the configuration for our migrations.
The connection string needs an additional sslmode=disable query string to not try to use SSL locally
macOS (no password, just your username): postgres://alexander:@localhost:5432/chirpy?sslmode=disable

Run the npx drizzle-kit generate command to generate the migration files based on our current schema state. These files are created in the directory you specified in the out field of drizzle.config.ts.
npx drizzle-kit generate

If everything looks like it should, run the migration.
npx drizzle-kit migrate
